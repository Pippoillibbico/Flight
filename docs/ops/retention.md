# Retention Operations

## Scope

Retention jobs enforce the published privacy and security retention policy for local file artifacts generated by the SaaS runtime.

## Schedule

Run daily at 03:00 server local time:

```bash
0 3 * * * cd /opt/flight-suite && node scripts/cleanup-sessions.mjs --apply >> docs/audit/retention-run.log 2>&1
5 3 * * * cd /opt/flight-suite && node scripts/cleanup-analytics.mjs --apply >> docs/audit/retention-run.log 2>&1
10 3 * * * cd /opt/flight-suite && node scripts/cleanup-logs.mjs --apply >> docs/audit/retention-run.log 2>&1
```

## Jobs

- `cleanup-sessions.mjs --apply`: deletes expired session, refresh-token, and auth artifacts after `SESSION_RETENTION_DAYS` days. Default: 30 days.
- `cleanup-analytics.mjs --apply`: deletes expired analytics, telemetry, and outbound artifacts after `ANALYTICS_RETENTION_DAYS` days. Default: 180 days.
- `cleanup-logs.mjs --apply`: deletes expired log and NDJSON artifacts after `LOG_RETENTION_DAYS` days. Default: 90 days.

## Evidence

Each execution must append its output to:

```txt
docs/audit/retention-run.log
```

Release approval requires a current retention run log showing `mode=apply` for all three jobs.
